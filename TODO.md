## Высокий приоритет

### ✅ Улучшить разрешение неоднозначных тайтлов через People API
**Проблема:** текущий подход (проверка credits у топ-3 кандидатов) не работает, если
правильный фильм не попал в топ-3. Пример: `«Рождение» Джонатана Глейзера` → тайский фильм.

**Решение:**
1. `GET /search/person?query={director_name}` → `person_id`
2. `GET /person/{person_id}/combined_credits` → полная фильмография
3. Нечёткое совпадение тайтла по фильмографии

Это надёжнее — мы сначала находим правильного человека, потом его фильмы.

**Статус:** ✅ Реализовано. Теперь при наличии режиссёра сначала ищется человек через People API, затем ищется нечёткое совпадение в его фильмографии.

## Средний приоритет

### Склонения тайтлов в поиске
**Проблема:** `«Вестворлда»`, `«Гамнета»` — TMDb иногда не находит по склонённой форме.

**Решение:** попробовать нормализацию через pymorphy3 или передавать в поиск оба варианта
(оригинальный + нормализованный).

### Обработка медиа-сообщений без текста
**Проблема:** форвард с фото/видео и подписью — `message.raw_text` пуст, но `message.message`
может содержать подпись.

**Решение:** проверять `message.message` если `message.raw_text` пустой.

### Ограничение: однобуквенные слова в директоре
**Проблема:** `_names_match` требует минимум 4 символа на слово — короткие фамилии
(Фон Триер, Ли) игнорируются.

**Решение:** снизить `MIN_STEM_LEN` до 3 или обрабатывать короткие токены отдельно.

## Низкий приоритет

### Поддержка OMDb API
Сейчас `OMDB_API_KEY` не задан — рейтинги не подтягиваются.
Получить ключ на [omdbapi.com](https://www.omdbapi.com/apikey.aspx) (бесплатный — 1000 req/day).

### Кэширование результатов TMDb
Один и тот же фильм может встречаться в нескольких постах подряд.
Простой in-memory TTL-кэш сэкономит API-квоту.

### Лимит слов в тайтле
Текущий лимит 1–7 слов отрезает некоторые длинные названия.
Проверить реальные случаи и при необходимости поднять до 9–10.

### Настройка SOURCE_CHANNELS через DM
Сейчас каналы-источники задаются только через `.env`.
Можно добавить команды `/add_source` и `/list_sources` для оперативного управления.
